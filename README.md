# Logging Mini Project 🚀

A simple and lightweight logging utility/project built to track application events, errors, and info efficiently.

## Features ✨
- **Log Levels:** Supports different levels like `INFO`, `WARNING`, and `ERROR`.
- **File & Console Output:** Saves logs to a file while also displaying them on the console.
- **Easy to Use:** Simple setup and integration into any small project.

## Technologies Used 🛠️
- Python 
- Standard Logging Libraries

## Getting Started 🏁

### Prerequisites
Make sure you have the required environment set up on your computer.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project directory:
   ```bash
   cd your-repo-name
   ```

## Usage 📖
Run the main script to see the logger in action:
```bash
python main.py  # या अपनी भाषा के अनुसार कमांड बदलें
```

Example code snippet:
```python
# Code example here
logger.info("This is an info message")
logger.error("This is an error message")
```
